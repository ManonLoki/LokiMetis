# 2026-10-11 决策记录

## ADR-006：今日总量放在桌宠同窗上方

change_id：`LMDESK-PET-TODAY-TOKENS-001`；required_version：`0.2.5`。依据当前会话用户对总量入口和两平台统一、节约托盘空间的明确要求，选择桌宠上方常驻摘要；这是已授权目标内的显示选择。

复用独立All今日投影，质量/缺失/过期规则由core统一表达。摘要固定预留32 DIP，原画布与播放实体不随数字变动；旧物理位置继续指向画布左上角，在原生边界换算完整窗口。来源重置和跨日撤下旧值，通知账本错误与摘要读取失败分开。

实际比对发现All已有总量而摘要显示无记录，原因是把全部来源就绪条件同时用于展示和通知。修正为Ready/ReadyNoCalls允许展示，并在来源未全部就绪时将Complete收紧为Partial；保留其它质量与置信度，通知仍只接受Complete+Exact。未扫描、需重扫和实际失败继续撤值。

风险是把旧日、未扫描或部分值误示为可信零，以及新增高度导致位置保存反馈。通过独立状态、来源代次、民用日与90秒时效和真实窗口回归约束。后续若改为其它入口，保留既有画布位置语义；不迁移用户原始数据，不以macOS开发检查代替两平台最终验收。

## ADR-007：穿透独立于锁定，并保留窗外恢复入口

change_id：`LMDESK-PET-MOUSE-PASSTHROUGH-001`；required_version：`0.2.5`。用户要求鼠标穿透，选择独立默认关闭的字段，避免改变原有锁定的双击、分页与缩放语义。

穿透走专用原生属性事务，复用既有字段保存队列与退出收尾。托盘直接取消、托盘打开配置和主窗口配置入口均独立于宠物点击。配置窗不参与穿透，原生确认未知时提供明确恢复动作，不将通用保存反馈作为唯一错误状态。

恢复意图即使等于当前展示值，也要递增读取代次并提交真实字段owner；store同值不落盘。否则启动默认false可能掩盖磁盘true，迟到读取重新开启。Windows只还原本功能增加的Layered位，显式关闭始终撤销Transparent；不重建整个扩展样式或改变renderer。真实Windows画面与跨应用投递仍需补证。
