# 2026-10-15 决策记录

## ADR-008：本次依赖维护发布采用补丁升版例外

change_id：`LM-DEPENDENCY-MAINTENANCE-RELEASE-20261015`；required_version：`0.2.56`。负责人在当前会话明确批准“本次例外，升至 0.2.56 后发布、推送并构建”，并选择启用代码审查、关闭 E2E。

原规则要求不改变可观察行为的维护不提升版本，同时禁止以同一或更低版本发布新源码。本次待发布变化为依赖升级及兼容适配，仍属于 maintenance，没有新增功能或独立产品缺陷。为使这些维护变化形成新的不可变发布，批准仅本次由 `0.2.55` 提升至 `0.2.56`；以后维护仍遵守原分类规则。

版本只通过现有 `$desktop-manage-version` helper 更新。其没有独立的维护发布增量命令，本次获准使用 `bug-fix` 数值通道和上述稳定 ID 完成一次 Patch 增量；该工具字段不表示发现了新产品缺陷。不得手改受保护版本状态，重复执行同一 ID 不再升版。

本次用户同时授权发布、推送和本地构建。保留长期 `post_release_action: local_package`，额外推送是本次明确授权的独立动作；只对唯一既有远端 `origin` 非强制推送已发布的同一提交及 tag，核对默认主分支、小写 `release` 分支和 tag。不配置远端或凭据、不移动旧 tag、不改写历史。

风险是工具中的增量分类与实际 maintenance 语义不同，以及依赖升级的宿主行为仍需实测。本 ADR 保留真实分类与一次授权范围；发布前复跑全量 Rust workspace 测试，绑定累计源码审查和版本一致性，构建再按真实模式记录产物检查。关闭 E2E 不表示安装或交互通过，macOS 本地 ad-hoc 试包不替代 Developer ID 签名、公证或正式候选资格。

例外在本次 `0.2.56` Git 发布完成后失效；以后不复用该例外扩展范围。恢复依据为上一不可变 `v0.2.55-20261014` tag；如需回退，另行授权新版本处理，不覆盖已发布引用。
