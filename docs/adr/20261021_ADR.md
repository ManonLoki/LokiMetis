# 2026-10-21 决策记录

## ADR-20261021-003：iOS桌面与锁屏小组件复用本地展示快照

状态：范围已确认，组件代码已接入，完整联动实施中。change_id：`LMDESK-IOS-WIDGETS-001`；required_version：`0.6.0`。确认来源为用户追加“iOS支持小组件和息屏组件”；“息屏组件”按锁屏WidgetKit布局解释，常亮展示服从机型与系统支持。

iOS提供桌面小号/中号及锁屏单行/圆形/矩形组件，使用原生WidgetKit扩展，和App读取同一份App Group展示投影。成功认证解密的snapshot消息才触发投影；固定有界文件原子替换，失败保留旧数据。共享内容只有Token日期/数字/质量与Hooks四态摘要，不包含配对凭据、Hook正文或图片。Widget不链接Rust/Kotlin，也不创建局域网连接。

此选择扩展系统展示入口，不扩大网络后台能力；此前不做云推送/息屏实时保证的决定继续有效。组件明确显示缓存和同步时间，没有同步或共享失败时保留真实空态。系统时间线和App请求的刷新只表示请求，不能作为设备当前在线或通知已送达的证据。涉及敏感展示使用系统privacySensitive机制，首次解锁前允许系统遮蔽。

理由是复用App已收到的数据能控制电量和隐私边界；代价是息屏期间数据可能停留在上次同步。缓存模型与失败保留由隔离单元测试覆盖，Swift宿主/扩展类型检查及Xcode目标/配置解析通过；实际签名App Group授权、锁屏添加、常亮效果和端到端同步尚未验证。后续若要求实时息屏更新、Live Activities或独立组件网络，应重新核对具体范围；不以本条授权云凭据、签名或渠道发布。

## ADR-20261021-002：移动端展示、设备管理与设置分离

状态：已确认。change_id：`LMDESK-TERMINAL-MENUS-001`；required_version：`0.6.0`。确认来源为用户当日明确要求“把配对部分归类为设备管理，移动端的名字等等收到设置中，展示部分称为独立的菜单”。

移动端拆为“展示”“设备管理”“设置”三个入口：展示承载Token/Hooks，发现与配对归设备管理，名称和本机信息归设置。切页仅改变页面会话，不启停应用级网络；名称明确保存后供下次连接使用。桌面同类入口统一称设备管理。此决定替代原移动端把名称输入、广播和未来展示放在同一页的组织方式；协议、后台恢复与纯局域网范围继续沿用下条决定。

调整使正常查看内容、建立连接和编辑本机信息各有稳定入口。实际配对/数据接收尚未完成时显示真实空态，不用演示内容假装可用。相关开发检查按本次提交说明记录；移动实机交互与iOS目标仍须后续核对。以后只有用户明确调整导航组织时才改变这三个职责，不借菜单改动扩大网络或设置能力。

## ADR-20261021-001：终端联动采用桌面数据服务与纯局域网恢复

状态：范围已批准、实施中。change_id：`LMDESK-TERMINAL-LINK-001`；required_version：`0.6.0`（plan）。确认来源：用户明确要求发现配对、设备信息与心跳、Token总量/分量、Hooks图片缓存，说明包含普通Android/iPhone/Watch，最终明确“无后端，还是先做局域网部分吧，不做息屏推送”。不将先前的云通知选择继续作为授权范围。

数据服务放在桌面，手机主动连接，桌面在同一连接内推送更新，图片按缺失请求传输。首次发现拟调整为手机发现桌面并报到后在桌面选中配对；四位码、共享Rust及A/B密码角色保持。该服务分工是根据用户场景作出的实施选择，不能据此承诺移动后台持续运行。

Watch采用iPhone配套路线；其状态与资源经WatchConnectivity同步。iPhone地址/心跳不能冒充Watch的IP或可达性，系统排队不表示手表已展示。独立Watch直连、云服务、APNs/FCM/厂商推送及息屏实时保证不在本次范围。

配对后业务连接采用独立随机交换、双向确认、方向密钥和严格序号，保留当前密码库未经审计及恒定时间限制。技术事实统一见[终端联动协议](../DEVICE_LINK_PROTOCOL.md)，不复制线格式。代价是两端增加原生Rust桥、缓存/恢复和服务生命周期；收益是数据权威与长期服务同属桌面，移动换IP可主动重连。

本条扩大[ADR-20261020-002](20261020_ADR.md#adr-20261020-002增加局域网设备配对阶段)中原先留待后续的接收端和业务数据范围；首次配对、私有保存、限流及其它仍有效限制继续保留。共享Rust/Android JNI/Apple C ABI取舍继续见[ADR-20261020-003](20261020_ADR.md#adr-20261020-003确认共享-rust-配对核心与移动端薄封装路线)。Linux历史授权与恢复例外仍按前一日期记录及其精确引用，不因本次联动扩大。

验证范围：当前桌面已接入共享会话、在线领域、受限TCP、Token/Hooks快照和图片分块；两端完整功能、实际配对、手机/Watch和各桌面平台仍须逐项验证。若后续要求息屏通知、独立Watch或直接扫描手机监听服务，重新核对对应范围与平台事实；不通过改状态文字掩盖未实现能力。
