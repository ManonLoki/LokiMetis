# 2026-10-09 决策

## ADR-001：以历史产品为 GPUI 复刻基准

change_id：`GPUI-PARITY-001`；required_version：`0.2.0`。

用户明确批准以历史代码和已安装 App 的完整体验作为本项目产品定义。复用业务 core，原生重写界面与宿主桥接；保留当前新产品身份、Logo、许可证和独立存储。历史源码与安装版本分别为 `0.3.15` / `0.3.12`，不修改历史仓库或其用户数据。

通用 `gpui-gui-common-v1` 的中性页面布局由已批准参考产品布局覆盖：三个业务导航，底部设置；业务页不使用 88px 独立页标题；公共设置容纳应用信息与支持内容。80px compact 几何保留。主题颜色、字体、卡片密度及二级导航按参考产品校准，不修改受管设计标准。

风险是外壳相似掩盖真实功能缺失。通过领域回归、真实数据流和分阶段 Computer Use 差异检查控制；任何未接通的能力保留未完成状态。回退依据为 Git 中性初始化提交 `f606d636b5464ca7f331223c7c63f37958e853cb`，不得回滚用户数据。

## ADR-002：复用历史 core 依赖

用户在当前会话明确许可 encoding_rs、jiff、sea-orm、sea-orm-migration、serde、serde_json、thiserror、toml、tokio 与测试 tempfile 按历史声明迁入。SQLite、JSON/TOML 与可靠时区/异步行为使用成熟实现可保持业务一致；所有依赖在工作区显式声明，不安装全局包。用户随后明确授权为达成完整复刻目标引入所需项目依赖，并要求后续不再例行询问；依赖仍需按实际用途在项目内显式声明，不做全局安装。

## ADR-003：统一 Agent 选择采用单一监控配置权威

统一选择只保存在本项目数据目录下的 `monitor/monitor-settings.json`，完整保留目录覆盖与桌宠偏好；看板的物理客户端集合和 WorkBuddy 开关从 core 能力目录派生，不额外持久化副本。历史产品的双文件回滚及启动 reconcile 用于旧存储升级，本项目独立命名空间没有该兼容负担，不读取原 App 的配置来迁移。

新安装缺文件默认启用 Codex、Claude Code、Cursor，明确空集合保持空。All 聚合、周期和升级扫描过滤停用项；WorkBuddy 停用时不探测文件。保留历史显式物理客户端读取与扫描能力，启动清理继续覆盖所有已有物理库。设置写入只修改目标字段，实际原子提交成功后更新界面；保存任务由应用 owner 持有，不随页面卸载取消。

监控配置读写共用128 KiB上限并拒绝非普通目标文件。设备主题/语言改为字段补丁与真实落盘回执，窗口几何独立合并，防止高频几何事件覆盖已保存偏好。本轮将 workspace 已声明的 tempfile 从 GUI 测试依赖提升为正式依赖以复用原子文件边界；未启动 Hook 写入、监听器或桌宠。

## ADR-004：监控端点和托管 Hooks 使用独立身份

change_id：`GPUI-MONITOR-001`；required_version：`0.2.0`（只读计划，完整监控尚未完成）。

本项目 relay 参数、标识头、rendezvous 文件与插件名统一使用 LokiMetris 独立身份，旧 LokiMetis 配置视为外来内容，合并和移除不得占用其标记。只监听随机的127.0.0.1端口，描述文件含实例 UUID；缓存描述由持有 OS 文件锁的发布者维护，先建立清理守卫再原子发布，退出仅清理仍属于自己的实例。共享第三方配置的后续写入锁仍应与原版协调，不能把独立应用身份误用为共享文件锁隔离。

工作台读取真实宿主投影，启用集合只在配置成功提交后改变准入。档案/图库/桌宠及真实 Hooks 写入继续按同一目标实施，当前检查点不安装 Hooks、不读取原 App 私有数据。

macOS 绘字前在当前进程的 NSArgumentDomain volatile 域将 AppleFontSmoothing 设为0，以接近参考灰度抗锯齿；保留已有域值，不调用持久偏好写入，不更改系统或其他应用设置。字体、间距与动画仍须后续实际窗口收敛。


## ADR-005：保留视口几何的 GPUI 图片圆角扩展

change_id：`GPUI-PARITY-001`；required_version：`0.2.0`（实施中，整体目标尚未完成）。

GPUI 0.3.8 的图片圆角使用图片与绘制边界的交集；Contain 留白小于半径时，交集的圆心不等于父视口圆心，无法表达历史 overflow/圆角裁切。采用可选原生绘制接口，将独立圆角视口随 PolychromeSprite 传入后端；原 paint_image 与 emoji 行为保持，图片仍使用同一个 Arc、帧索引和 atlas 条目，不增加整图重采样、角部小纹理或背景遮挡。

现有依赖版本保持0.3.8，项目内隔离 gpui-pre、gpui-pre-apple、gpui-pre-windows 与 gpui-pre-wgpu。完整官方归档原样保存在各 upstream，逐文件 SHA-256 和清单固定锚点注册；小型 shim、标准库生成器及严格唯一替换模板在 OUT_DIR 产生编译内容，禁止手工修改上游或生成物。维护代码、模板与测试照常接受规模约束，不将 vendor 整体排除。Metal、DirectX、WGSL/WebGL 同步图元 ABI；公开结构变化必须覆盖所有这些后端。

生成层已通过固定SHA、严格模板与cbindgen镜像验证；真实Window接口回归、compiled-Metal像素RED→GREEN及WGPU独立Naga／ABI回归已执行。Monitor消费者与生命周期回归仍在接入；WGPU完整lib测试因官方归档缺少包外字体夹具未执行，独立回归不能冒充该组通过。macOS通过不能替代Windows HLSL编译和DirectX实物。风险包括 ABI 对齐、透明边缘采样和上游维护成本；通过旧接口/emoji、真实 GPU 像素、同帧 atlas 复用和隐藏/卸载资源回归约束。

当官方 GPUI 提供等效独立圆角视口，并通过本项目相同几何、资源、真实像素和两平台 Computer Use 回归后，移除四个本地补丁与生成层；不能只为删除补丁而跨版本替换框架或取消失败验证。
