# ADR：2026-10-01

## ADR-001：前端模块与样式命名整理，并移除“清空本产品索引”命令链

- 状态：Accepted；用户于 2026-10-01 明确授权目录搬迁、组件提取、共享对齐机制、面板标记类与后端无调用命令的清理。
- 背景：2026-09-30 的 UI 统一改造后，共享样式与组件散落在不匹配的文件与目录中；`ADR-20260930` 中记录的类名和路径因此过期（该 ADR 作为当时的决策记录保持不变）。
- 决定：
  - 命名：`ai-tool-tabs → app-tabs`、`dashboard-toolbar → page-toolbar`、`dashboard-page-nav → page-nav`、`dashboard-header-row → page-toolbar-row`；主题变量 `--app-dashboard-toolbar-* → --app-toolbar-*`、`--app-dashboard-nav-* → --app-nav-*`。悬停光晕面板统一使用标记类 `spot-panel`，`useSpotlight` 与 `panels.css` 共用它。
  - 样式文件：新增 `styles/panels.css`（面板材质与悬停）与 `styles/controls.css`（按钮反馈、分段控件、标签页）。
  - 目录：设置页部件进入 `components/settings/`，`SettingsPage` 进入 `pages/`；看板、监控、数据源部件分别进入 `components/dashboard|monitor|sources/`；`UsageUi` 进入 `components/usage/`，通用状态面板拆为 `components/StatePanels.tsx`；页面 hooks 进入 `src/hooks/`，纯函数进入 `src/lib/`；`state/page-session.ts` 改名 `state/usage-view-state.ts`。
  - 组件：新增 `MiniMetric`（含 `dense`）、`EmptyHint`（`compact`/`size`/`tone`）、`EndTh`/`EndTd`（数值与操作列右对齐）。
  - 后端：删除无调用的 Tauri 命令 `get_source_roots` 与 `clear_local_index`，以及 `ClearIndexResultDto`、`PrivacySettingsDto.lastClearedAtEpochMs`、`UiMessageCode::IndexCleared`、核心清空文案函数与适配层 `clear_index`/`open_index_for_write`/`mark_index_cleared`；核心 `LocalIndex::clear_index` 及其测试保留。
- 风险与恢复：前后端 IPC 契约收窄，旧前端若仍读取 `lastClearedAtEpochMs` 会得到 `undefined`（本仓库前端已同步移除）。恢复“清空索引”需要重新引入命令、DTO、文案与前端入口。
- 版本：维护性整理，不提升版本。
