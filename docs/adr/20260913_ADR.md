# ADR：2026-09-13

## ADR-001：兼容皮肤应用不重复询问第三方代码信任

- 状态：Accepted；用户于 2026-09-13 明确要求移除应用时的重复确认，并指出旧交互门禁设置不符合预期。
- 背景：已在资源库中的兼容皮肤每次点击“应用”仍弹出第三方代码信任确认；导入阶段已对含 `renderer-inject.js` 的包取得显式信任，重复弹窗阻碍直接应用。
- 决定：用户点击资源卡的“应用”就是本次执行动作；前端直接进入原有安装流程，不再展示应用时的第三方代码弹窗。导入兼容皮肤时的显式信任、后端 `allowThirdPartyCode` 校验、宿主身份和回环端点验证，以及破坏性重启和外观不匹配确认保持各自边界。
- 风险与恢复：用户若绕过应用内导入流程直接把兼容皮肤放入本机资源目录，点击“应用”即可执行其脚本；资源卡仍标明兼容皮肤类型。若后续要恢复逐次确认，需重新批准产品交互并补回前端门禁与回归测试，不得由发布审查自行改变本决定。
- 版本：`change_id = BUG-LEGACY-SKIN-REDUNDANT-APPLY-CONSENT-20260913`，`required_version = 0.3.6`。
