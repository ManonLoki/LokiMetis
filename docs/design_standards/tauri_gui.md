# LokiMetis Tauri GUI 通用设计标准

本标准稳定标识为 `tauri-gui-common-v1`，适用于 LokiMetis 的 Tauri 2、React、TypeScript 与 Mantine 展示层。业务规则和权威状态仍归 shared core。

## 设计原则

- 优先清晰层级、稳定间距、可预测交互和真实状态，不以装饰覆盖信息结构。
- 主色、字体、字号、行高、间距、圆角、阴影、断点和组件默认值集中在 `createTheme`；页面与组件不复制品牌色或主题 token。
- 仅使用语义主题颜色，所有前景/背景/边框/焦点状态同时验证浅色、深色和跟随系统模式。
- 使用 Mantine 组件表达标准控件，使用 Tabler Icons 表达图标；避免手写 SVG、emoji 或字符图标。

## 窗口与布局

- 默认窗口 1440×900、最小 960×640、居中。持久状态无效、损坏、越界或不与显示器工作区相交时回退默认。
- 左侧导航完全遵守 [`tauri_sidebar.md`](tauri_sidebar.md)；页面不得自行改变侧栏宽度或主内容偏移。
- 内容区使用流式宽度和 Mantine 断点；表单、卡片、对话框和数据区不得依赖仅适合默认窗口的固定宽度。
- 横向滚动只用于数据本身不可压缩的区域，并提供明确边界；普通页面不得产生整体横向滚动。

## 文案、身份与版本

- 窗口标题固定为 `LokiMetis`，不带版本号。设置页等可见版本经共享 formatter 保证只有一个小写 `v`。
- Logo 只使用 `/app-identity/logo.png` 的本地批准资产；不得从网络加载品牌资源。
- 所有用户可见字符串进入 `zh-CN` 与 `en-US` 翻译资源；未知语言回退英文。不得把翻译文本用作程序逻辑、持久键或测试选择器。
- 设置、标题、应用元数据和侧栏不显示联系人，不提供隐私、统计、遥测或应用更新文案。

## 控件与事件所有权

- 动作绑定在实际语义控件：Button、ActionIcon、Link、Switch、Checkbox 或菜单项。Card、行、单元格、标题和说明不代理子控件动作。
- Switch/Checkbox 使用稳定 ID、`aria-labelledby` 与 `aria-describedby` 关联可见标题和说明；异步时禁用自身并展示局部 loading。
- 破坏性或不可恢复动作必须明确标注影响和目标，按风险要求确认；取消始终安全且不产生副作用。
- tooltip 不能承载唯一信息，hover 不能成为唯一入口；键盘操作、焦点顺序和焦点环必须完整。
- dialog 只用于真实用户动作，错误信息说明发生了什么、未发生什么和可采取的下一步，不泄露敏感路径或载荷。

## 状态与反馈

- loading、empty、error、success、disabled 必须可区分，不用空白或永久 spinner 代表未知状态。
- 异步操作只在真实成功后更新界面；失败恢复 Rust/OS 权威状态并允许安全重试。
- 通知偏好与 OS 通知权限是不同事实；自启显示 OS 注册真实状态。两者的 Switch 只由自身操作触发。
- 页面会话状态在应用根 Jotai store 中进程内保持；TanStack Query 拥有服务端/异步数据。界面不得复制 core 的权威业务状态。
- 查询成功但大于 1 的当前页为空时可回到第 1 页；加载、取消、超时和错误不得触发空页回退。

## 固定支持界面

- `/settings` 固定展示应用、版本、本地更新日志、语言、三态主题、通知偏好、自启状态与唯一 Agent 复选面板。用量看板的物理 Agent 与 WorkBuddy 横向导航在「数据源」后显示「设置」，对应 `/dashboard/settings` 且只承载扫描间隔与自动清理；「全部」视图不显示该入口。Hooks 目录与写入表单只位于 `/monitor/settings`，只投影全局已启用 Agent 且不复制复选面板。
- 发布日志从候选内 `release-notes.json` 异步读取，提供 loading、error、retry；首次发布前缺失资源是可重试错误，不使用假数据。
- `/about`、`/sponsor`、`/test` 及相应入口、组件、翻译键和媒体必须缺席。
- 不提供在线版本检查、下载、安装、产品统计或远程遥测控件。

## 无障碍与国际化

- 所有可操作元素有可访问名称，输入有标签，图标按钮有与动作一致的名称；状态变化通过可感知文本或合适 live region 呈现。
- 文本和关键控件达到 WCAG AA 对比度；颜色不是唯一状态线索。
- 键盘能够完成所有流程；焦点不会被路由、dialog 或异步刷新丢失。关闭 dialog 后焦点回到触发控件。
- 为中英文长度差异预留空间；不得通过不可访问的省略隐藏关键操作或错误。
- 动效尊重 reduced motion，且不影响完成任务。

## 最小回归

- 默认/最小窗口、浅色/深色/跟随系统、中英文、键盘与焦点。
- 窗口标题为 `LokiMetis` 且不带版本、设置页版本单 `v`、Logo 可见、compact 侧栏几何与当前路由。
- 设置页应用/版本/本地发布日志的成功、错误与重试，以及通知/自启成功和失败回滚。
- Switch 与父级周围区域分别点击，证明只有控件触发动作并具有正确名称/说明关系。
- 路由卸载/重挂载后的进程内页面状态、全新 store 的默认状态和分页空页边界。
- 扫描 `/about`、`/sponsor`、`/test`、全局快捷键、updater、统计与远程遥测残留。

组件测试和开发预览只验证局部合同；发布验收必须操作真实最终候选。
