# LokiMetis compact 左侧栏标准

本标准叠加于 [`tauri_gui.md`](tauri_gui.md)，稳定标识为 `tauri-gui-sidebar-compact-80-v1`。它只属于 GUI adapter 展示层，不进入 core。

## 固定几何

- `AppShell.Navbar` 宽度固定 80px，不提供展开、收起或拖拽。
- 主内容左侧内边距固定 6px；宽度和内容偏移从同一常量导出，禁止在 CSS、页面或组件重复字面量。
- Logo 使用 36×36px 可视框，保留图片比例与完整安全区，不裁切、不拉伸。
- 导航图标统一 22×22px，优先使用 `@tabler/icons-react` 命名组件。
- 品牌名、版本与导航名称占满侧栏可用宽度并水平居中，不使用固定 `em/ch` 文本盒。

## 结构

1. 顶部品牌区：Logo、`LokiMetis`、格式化后的单 `v` 版本。
2. 中部功能导航：从上向下增长；中性基线不虚构业务入口。
3. 底部固定设置入口；赞助入口必须缺席。

Logo、图标和可见名称沿同一中心线。每个导航项的语义动作由其自身 Link/Button 拥有，父级容器不得代理点击。活动路由通过 `aria-current="page"` 和主题语义色表达，不能只依靠颜色或动画。

## 交互与可访问性

- 当前侧栏不可折叠，因此不得出现折叠按钮、折叠 Tooltip、设备偏好或 navbar 宽度切换状态。
- 每个入口保留可见文字和完整可访问名称，图标设为装饰性或提供与文字不重复的语义。
- 键盘 Tab 顺序与视觉顺序一致；焦点环在明暗主题均可见，点击区域不得透明覆盖相邻项。
- 中英文文本可换行但不得裁切或与图标重叠；长文本应在 80px 布局内经真实渲染验证。
- 窄窗口时侧栏仍为 80px，主内容负责响应式布局，不通过缩小触控目标或隐藏名称规避。

## 验证

- 结构/组件测试锁定 80px、6px、36px、22px、不可折叠和底部设置入口。
- 交互测试验证当前路由、高亮、键盘、父容器零动作和可访问名称。
- 在中英文、浅色/深色/跟随系统主题、960×640 最小窗口与 1440×900 默认窗口中检查无裁切、偏移和重叠。
- 像素或信息架构偏离必须先在 `docs/GUI_APP_PROFILE.md` 记录精确差异并关联已批准 ADR。
