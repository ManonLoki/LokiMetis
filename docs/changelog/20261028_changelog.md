## LMDESK-CARD-TECH-MOTION-001 · 全页面卡片分层与科技动效

分类：feature；required_version：`0.11.0`。

看板、监控、皮肤、设备与公共设置的卡片统一采用主要/次要/辅助三级材质。关键指标、监控工作台及当前皮肤加入青/紫/玫红环绕光轨和轻微边缘呼吸；工作面板采用细角标与悬停流光；细分指标、筛选、表格、系统偏好和空状态使用静态内嵌表面。明暗主题、圆角、可访问标签和子控件动作保持。

动效由原生路径绘制，不逐帧生成图片；隐藏、失焦、离屏与减少动态效果时暂停，恢复不补算后台时间。卡片装饰属于GUI展示，不改变core业务状态、设备信任或数据口径。视觉合同见[GUI资料](../GUI_APP_PROFILE.md#卡片层级与科技动效)。

同一视觉改造的补充调整：多维用量分布图将本地 Token 约数与精确整数分为上下两行，保留右对齐及完整辅助标签；调用计数和缺失值仍为单行。补充的2项绘图/图表接入回归通过；两行排版尚未执行实机截图检查。

开发验证：301项受影响卡片与页面回归，以及1项补充静态层级/输入所有权回归通过。包含光轨闭合/内收/暂停/恢复、macOS真实Metal明暗像素、原生按钮输入、页面宽窄布局、资源释放与语义保持。未执行安装包、Computer Use、Windows/Linux实物或最终候选验收。
