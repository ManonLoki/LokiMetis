# 2026-10-22 开发变更

## LMDESK-CURSOR-TOKEN-USAGE-001 · Cursor 账户 Token 明细

分类：feature；required_version：`0.8.0`。

用量看板新增独立“Cursor 账户”入口。启用 Cursor 后可按今日、昨日、本周、上周、本月、上月查询账户级 Token 事件，展示输入、输出、缓存读取和缓存写入四分项，并按日期与模型汇总。每字段显示已报告条数，缺失不补零，不虚构完整总 Token。账户数据可能包含其他设备，明确排除本机全部、通知、桌宠与终端本机 Token。

复用只读登录材料与现有受限传输，完整分页后才发布；不完整响应显示失败。内存结果按账户、窗口与时区隔离，五分钟节流，可显式重新读取；换页、取消和退出回收自有读取进程，不新增依赖或业务持久化。产品决定见[ADR-20261022-004](../adr/20261022_ADR.md#adr-20261022-004cursor-token-采用独立账户分项来源)。

开发验证：core `cursor_usage::` 7 项；GUI `cursor_` 14 项、`usage_service::provider_quota::` 21 项、`app::settings::agents::tests::` 2 项通过（各筛选含重叠测试，不作独立总数相加）。覆盖完整分页、部分字段、溢出、DST、账户隔离、失败节流、强制刷新、超时/运行中取消及进程回收、只读数据库与令牌不进入参数、原生日期按钮归属和会话状态。中英文新增键与受影响文档相对文件链接检查通过。

新增读取前，本次对话已只读实测当前账户网页接口三页完整返回205条，其中200条有Token明细；该诊断不等同新应用候选验收。未打包、替换安装程序、执行最终E2E或验证Windows/Linux。个人账户网页接口可能变化或延迟，缺少curl/sqlite3仍需按明确错误处理。
