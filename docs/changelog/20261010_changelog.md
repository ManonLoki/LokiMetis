分类：feature。required_version：`0.2.1`。本周期功能锁已应用，本次登记不再次提升版本，未发布。

实机发现并修正 zoom 动画中间尺寸覆盖普通记录、最大化迁屏丢失屏幕身份，以及桌宠可见时上游吞掉应用重开事件的问题。原样第三方源码保持不变，宿主补丁通过精确模板与生成摘要约束；系统直接 unzoom 保留 AppKit 原生行为。

本事件只交付 macOS 主窗；两块实机屏均2×，混合DPI、拔屏、系统全屏失败、Windows及桌宠/配置窗/托盘定位仍未验证或未完成。没有性能测量或正式候选结论，整体复刻目标继续进行。
