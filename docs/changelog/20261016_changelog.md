# 2026-10-16 开发变更

## LMDESK-TRAY-NOTIFICATIONS-001 · 托盘自启与系统通知规则

分类：feature。required_version：`0.3.0`。本发布周期首个功能将版本从`0.2.57`提升至`0.3.0`，未发布。

托盘新增开机自启，复用设置页的串行OS服务；勾选只取真实读回状态，忙碌期间禁用，未知/失败时可点击重新读取，双语标签同步更新。

Token通知替换旧每100M规则：当天可信总量首次严格超过1B才产生一个事件，后续增长与回落反弹均不重复；中文正文为“恭喜您已使用{总量}的Token”。账本策略升级为2，并使用m2稳定ID隔离旧回执；旧队列、预约与重试不再派发，第10档的严格边界由新可信基线决定。预约、Unknown、退避和退出持久化继续由原owner负责。

Hooks新增询问、结束、错误状态变化通知，正文分别为“{Agent}需要您决策”“{Agent}已完成”“{Agent}出错了”，Agent显示名与公开目录一致。工具自身保存通知前态，避免桌宠同槽覆盖导致漏报；重复状态、启动空闲、失活回收和结束后的释放静默，过程错误后的正常停止仍通知结束。Codex/WorkBuddy实际换肤成功或失败均通知，确认/取消不误报。结果观察位于应用后台owner，离页不吞掉已提交事务的真实终态。

三类通知共用已确认的总开关、系统权限和原生发送owner。Hooks/换肤使用有界短时内存邮箱，不依赖今日用量读取成功，不保存Hook内容或失败路径；macOS原生代理识别新策略与瞬时事件ID并保留点击恢复。

核心132项、GUI去重后87项相关回归通过，共219项。覆盖阈值/跨日/迁移、Hooks状态机与监听、换肤回执、原生通知、托盘和自启。未执行真实OS横幅/点击、实际登录启动、Windows宿主或候选打包；本地开发回归不代表发布验收。
