# 2026-10-21 开发变更

## LMDESK-IOS-WIDGETS-001 · iOS桌面与锁屏小组件

分类：feature。required_version：`0.6.0`（沿用本周期功能版本）。

移动项目新增WidgetKit扩展，支持桌面小号/中号和锁屏单行/圆形/矩形，App设置页提供添加说明。组件展示最近同步的Token总量/分量与Hooks状态摘要，保留日期、质量与缓存时间；未收到真实数据时显示尚未同步。App成功解密的snapshot入口接到同一展示投影及App Group原子文件，组件只读缓存，不包含密钥、Hook正文/图片或持续网络任务。

开发验证：8项Swift宿主单元测试通过，覆盖u64/质量/零与缺失、私密字段丢弃、释放后的完整替换、无效更新与失败写入保留、损坏/超大文件和链接拒绝。使用真实iOS模拟器SDK进行Widget扩展及App全量Swift源的类型检查通过（复用已有Kotlin框架头文件）；Xcode目标列表与实际扩展配置解析通过。未执行完整App构建、签名App Group授权、iPhone锁屏/常亮实测或端到端局域网同步；主联动目标继续实施中，没有增加云推送或发布。

## LMDESK-LAN-DESKTOP-SERVICE-001 · 桌面局域网数据服务

分类：feature。required_version：`0.6.0`（本周期功能锁已开启，不重复提升Minor）。

桌面广播自己的局域网数据服务，接受终端主动报到，在用户输入四位码并真实私有保存后授信。已保存设备可用新随机会话恢复连接；设备页显示经过认证的名称、实际IP、平台版本，以及心跳可达、后台暂停和最后通信信息。

桌面沿加密双向连接推送同轮今日Token总量/各Agent分量和Hooks最终槽位展示；共享发布器仅在有终端时周期读取数据。图片发送内容摘要清单，终端按缺失请求逐块获取，完整长度/魔数/SHA-256校验后才允许保存。慢设备只保留最新快照，不积压更新；坏包、旧序号、错误元信息、超时及撤销关闭连接。应用级owner回收阻塞读取和网络任务，旧启动快照不能恢复已移除的信任。

本阶段为桌面数据服务与共享协议；Android/iOS原生桥、终端私有缓存、实际重连和Watch协作仍未完成，主目标`LMDESK-TERMINAL-LINK-001`保持实施中。当前服务为IPv4局域网，不提供云服务或息屏推送。

开发验证：共享密码库16项、设备core21项、GUI设备/网络/存储/页面23项、今日缓存/分量5项、来源与质量11项回归通过；macOS本地网络声明2项通过。环回TCP覆盖真实四帧配对、会话认证、快照推送、资源分块与持续请求期间状态发送；隔离数据夹具不替代实际手机、Watch、真实LAN或桌面跨平台验收。未构建最终包、发布或推送。

## LMDESK-MOBILE-PROTOCOL-BRIDGE-001 · 共享移动协议桥

分类：feature。required_version：`0.6.0`（沿用本周期功能版本）。

增加不依赖GUI/数据库/运行时的C ABI桥，Android JNI与Swift使用同一配对及恢复状态机；独占注册句柄、固定有界缓冲与稳定错误不暴露内部密码对象。首次配对拆为验证、真实OS保存和确认回执，material没有提前ACK；独立commitId阻止迟到保存回调误确认新材料。共享窗口持有60秒期限、5次总预算与单在途尝试，重连不重置；资源接收/完整摘要校验移入同一轻量共享库供桌面和移动桥复用。

开发验证：共享pairing20项、mobile_bridge5项、core设备20项及GUI设备23项回归通过。C ABI在Rust宿主测试中覆盖真实缓冲和句柄边界；没有据此宣称Android/iOS原生加载通过。移动项目的Kotlin驱动编译及5项已有HostTest通过，包含配对存储/缓存/桥的源代码编译；这些HostTest未调用真实Keystore、NDK或手机网络。Xcode工程语法解析通过，Swift目标构建与Keychain真实执行未验证。

手机发现/连接controller、完整展示、实际缓存/恢复与Watch仍在实施；本阶段不将原有广播页面标为配对已开放，不发布或签名。

## LMDESK-TERMINAL-MENUS-001 · 设备管理、展示与设置分离

分类：feature。required_version：`0.6.0`（本周期功能版本保持不变）。

按用户要求将配对归设备管理，移动端独立提供“展示”“设备管理”“设置”菜单；名称编辑、设备ID等本机信息放进设置。名称明确保存后供下次连接使用，保存与切页不启停网络，配置草稿跨菜单保留。桌面“设备”导航和页面标题同步改为中英设备管理名称。

移动端页面与设置回调已修改；当前没有真实接收数据时展示未连接空态，配对接入未完成的事实继续明确显示。Android的sharedUI/sharedLogic编译及既有HostTest通过，桌面设备页4项回归通过，包含双语入口/标题、模态和按钮所有权。既有HostTest没有执行菜单点击或系统设置保存，未进行iOS目标构建、实机菜单交互或完整联动验收；未发布或推送。
