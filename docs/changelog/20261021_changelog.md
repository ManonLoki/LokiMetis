Android/iOS从系统取得手机/平板类别，在当前认证快照能力协商后上报；桌面插图不再读取设备名称。旧端保持连接兼容，未报告类型时显示中性图标。形态由core绑定当前租约，不迁移账本，重连重新报告；Watch继续作为iPhone子设备。协议与系统限制见[终端联动协议](../DEVICE_LINK_PROTOCOL.md#终端自行上报设备形态)。

本次只做相关开发回归；真实平板互通、iOS完整应用与跨平台最终候选尚未验证，未发布或推送。


## FEAT-WIDGET-HTTP-V1 · 小组件独立HTTP获取桌面摘要

分类：feature。required_version：`0.7.0`。

桌面提供固定局域网HTTP只读摘要入口，手机在认证连接后保存实际服务地址及独立读取权限，下次连通更新。小组件由系统调度独立拉取，离线保留上次同步时间；来源切换、忘记配对、地址换代与较新数据到达后阻止旧响应覆盖。无TCP连接时请求也能唤醒同一统计发布器；不增加云推送、长连接或准点刷新承诺。长期配对秘密、Hook正文及图片不进入Widget共享摘要。
