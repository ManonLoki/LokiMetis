勾选和禁用属性的自动化证据来自测试平台；当轮系统菜单截图不可用，不能据 AX 文案宣称原生勾选字形或忙碌期间的 AppKit 自动校验已通过。顶层应用菜单仍显示包内英文名称 `LokiMetris`，中文菜单项正确。Windows、登录启动、系统通知横幅/点击和正式候选验收未执行，整体体验复刻继续。


## LMDESK-PET-TODAY-TOKENS-001 · 桌宠上方显示今日 Token 总量

分类：feature。required_version：`0.2.5`；同周期功能锁不再次提升，未发布。

桌宠同窗上方增加固定32 DIP摘要，复用既有独立All今日聚合。可信零、无记录、等待、失败、过期分开显示，部分与推算披露质量，窄窗缩略并保留精确可访问文案。读取来源代次只绑定本轮查询，切换来源立即撤下旧数；同源读取失败也会撤值，并归还尚未派发的旧通知预约。通知账本损坏不影响有效摘要。前台只取Copy投影，不查询时区或磁盘，同值观测更新时间不重绘。

原画布尺寸、分页与播放器保持，保存位置仍表示画布物理原点。完整外框包含摘要高度，恢复和保存只各换算一次。首轮领域6项、相关GUI/服务64项通过；首图测试曾把初始位置保存计入分页revision，修正为先确认位置落盘再核对分页一次，补强后的该项单独重跑通过。无条件通知错误变体真实失败，修正后64项重新通过。

随后Computer Use发现All已有89,471,909 Token，桌宠却显示无记录。领域及真实SQLite worker新增回归均先复现失败，确认是未配置的启用来源阻断了展示。现Ready/ReadyNoCalls保留已有整数，来源未全部就绪时Complete收紧为Partial；已有其它质量和置信度保持，未扫描/需重扫及失败仍撤值，部分总量不能推进通知档位。修正后领域7项、相关GUI/服务65项通过。

macOS开发预览已用Computer Use读回All与桌宠同为99,257,782；窄窗缩略带质量标记，宽窗显示完整短摘要，精确整数和质量保留在AX文案。翻页及顶栏右键/双击/滚轮保持摘要和画布；宽窗重启后474×222物理尺寸、分页及保存位置字节不变。检查用布局、尺寸和位置已还原，偏好/档案/设置字节与模式核对通过，原未保存图片草稿经界面恢复。

证据保留于忽略的 `release/pet-today-tokens-development-20261011/`；画布绝对屏幕原点未另作原生测量，不据裁剪截图宣称绝对坐标已验收。本记录不代表正式候选或整体体验一致。系统时区缓存、Windows动态缩放限制与原有同格非比例resize仍须后续补齐。
