## LMGUI-BUTTON-PRESS-SCALE-001 · 按钮按压整体缩放并取消隐藏前的旧动作

分类：bug-fix。required_version：`0.2.16`，未发布。

历史按钮按压采用200ms共同过渡，围绕原border-box中心缩至98.5%并下移1 DIP。背景、边框、圆角、文字、图标和加载层共享绘制变换，布局占位和兄弟元素不变；实际命中与原生辅助边界同步变换。字形和SVG沿用已有纹理参数，不把逐帧缩放转换为字体或图片重新栅格化。缓存与延迟绘制保存变换，Scene回放不重复应用。

隐藏窗口立即撤下按压反馈并按鼠标、键盘分别取消旧动作；另一模态的新按下和OS重复持键均不能复活旧release。重新输入仍由原Button触发一次，保留原回调覆盖语义。

共享按钮13项、来源按钮5项、真实CoreText与Metal截图1项、补丁生成器5项通过。截图回归要求字形像素非空，同时检查0.985和0.5比例、父兄弟像素不变和释放后精确恢复。只含本轮改动的源码快照生产编译通过；该快照的单元测试编译暴露既有重新索引测试与返回类型不一致，故不记为隔离测试通过。当前共享工作区的相关测试已通过，保留另一会话的清理及裁切改动。

本地v0.2.16试包发现1515项测试、汇总1521次通过（含6次隔离子进程计数）。Computer Use实际检查目录选择/取消、重命名单弹窗及Tab聚焦/Space取消；原来源与新旧应用偏好字节保持。按住期间实物截图未取得，原生禁用辅助字段仍有遗漏；鼠标打开保留之前焦点，取消后Enter无动作未判为恢复缺陷。弹窗材质/字体/文案与历史尚有差异。性能经验已补入专门文档5.33，本轮未测CPU/内存收益。Windows和整体体验一致性未通过。

## LMDESK-CODEX-FORK-OWNER-001 · 按响应身份确认 fork 用量并保留旧记录歧义

分类：bug-fix。required_version：`0.2.9`，未发布。

Codex fork 的首个 task_started 可能晚于创建时间，不能仅凭两秒时间窗口确认本线程。有效现代响应的 thread_id 与当前元信息身份一致时，现在可独立确认该响应归属；明确属于其它线程的响应忽略，非法身份、用量或时间不能开启归属。只有初始化信息、尚无用量的 fork 保持可信零。先前出现过无法归属的 legacy 用量仍保留不完整警告，不因后续现代响应清除。

解析器版本提升到 11，checkpoint schema 提升到 4；旧状态及缺少必填歧义字段的状态要求重建。歧义状态跨重启、半行续写和增量扫描持久化，稳定响应 ID 及不可覆盖账单规则保持。

本地索引相关 233 项测试、核心策略 41 项测试通过，独立只读代码审查未发现实质遗漏。真实数据只读诊断确认 20 个 fork 首条本线程现代响应之前没有 legacy 用量，另 2 个只有初始化记录；开发预览重扫、系统通知横幅及点击留待本轮 Computer Use 检查，不据开发测试宣称正式验收或整体体验一致。


## LMDESK-NATIVE-MENU-AUTOSTART-001 · 系统菜单接入开机自启并保持界面语言

分类：feature。required_version：`0.2.4`。本周期功能锁已应用，本次登记不再次提升版本，未发布。

系统应用菜单新增开机自启，复用既有串行登录项服务。勾选投影取系统已确认值；忙碌或未知时禁用，动作处理也拒绝重复及未知状态写入。自启 revision 变化会刷新菜单，初始化不注册登录项。通知入口继续复用已保存偏好与独立权限状态。菜单语言由应用级显式选择持有，异步状态刷新不再读取未同步的进程默认语言。

38 项相关原生回归通过，其中新增四项覆盖真实测试平台菜单的动作类型、文案、勾选、禁用和应用间语言隔离。恢复旧全局语言读取方式的错误变体按预期失败，随后恢复源码并重跑通过。

macOS 开发预览已用 Computer Use 检查中英文菜单操作与设置页双向状态同步；实际登录项开启时指向同一预览二进制，关闭后已确认不存在。中文、系统主题、通知关闭和原监控档案保持原值，未保存的运行中图片草稿经界面恢复。AppKit“恢复原大小”读回与原几何相差 1 DIP；后续已正常退出预览，仅几何字段有差异，偏好字节已精确还原。原轮证据保留于忽略的 `release/native-menu-development-20261011/`，还原证据见 `release/macos-menu-ownership-development-20261011/08-preferences-restored.json`。

勾选和禁用属性的自动化证据来自测试平台；当轮系统菜单截图不可用，不能据 AX 文案宣称原生勾选字形或忙碌期间的 AppKit 自动校验已通过。顶层应用菜单仍显示包内英文名称 `LokiMetris`，中文菜单项正确。Windows、登录启动、系统通知横幅/点击和正式候选验收未执行，整体体验复刻继续。

原画布尺寸、分页与播放器保持，保存位置仍表示画布物理原点。完整外框包含摘要高度，恢复和保存只各换算一次。首轮领域6项、相关GUI/服务64项通过；首图测试曾把初始位置保存计入分页revision，修正为先确认位置落盘再核对分页一次，补强后的该项单独重跑通过。无条件通知错误变体真实失败，修正后64项重新通过。

## LMDESK-PET-MOUSE-PASSTHROUGH-001 · 桌宠增加独立鼠标穿透和恢复入口

分类：feature。required_version：`0.2.5`；同周期功能锁不再次提升，未发布。

桌宠偏好增加默认关闭的鼠标穿透，旧配置和无效字段保持关闭。穿透与置顶、锁定及布局独立；macOS 写入活 NSWindow 的 ignoresMouseEvents 并读回，Windows 保存并合并本功能拥有的扩展样式位。单独切换不调用尺寸、位置或播放器重建路径。配置窗口自身保持可交互，主窗口设置与托盘提供独立恢复入口；未知原生状态持续显示提示，不能因其它操作清除错误文字就冒充已确认。

显式取消穿透即使偏好已经为 false，也会重新确认原生窗口并提交字段意图，使旧加载结果失效。失败回滚、排队、退出保存和字段合并均复用应用级 owner。核心4项、桌宠64项、监控设置14项、托盘1项相关回归通过。把同值取消恢复成提前返回的错误变体真实失败，恢复源码后桌宠64项重跑通过。

macOS 开发预览 Computer Use 检查了独立开关、配置可交互、主窗口恢复、保存并重启及取消恢复；置顶和锁定未被连带改变。原偏好、档案、设置的字节和文件模式已还原。临时原生观察发现覆盖位置的工具合成事件坐标与截图目标不符，不能用该点击证明 WindowServer 的实际穿透命中；原生属性读回和这些界面检查不能替代真实鼠标验证。观察代码已移除，证据保留于忽略的 `release/pet-mouse-passthrough-development-20261011/`。实际跨窗口鼠标命中、托盘原生勾选外观及 Windows 编译/宿主交互仍为 Unverified，整体复刻继续。
