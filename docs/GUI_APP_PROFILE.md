## UI 设计与宿主基线

产品复刻差异按[当前产品规格](product_spec/20261022_product_spec.md)的批准范围维护：保留当前名称、Logo 和独立应用身份；业务导航为用量看板 / AI监控 / 应用换肤，底部设置；参考产品的二级导航与卡片取代中性 88px 页面标题。compact 仍为 80px。参考主题/密度逐阶段通过 Computer Use 校准。应用信息已迁入公共设置，移除旧中性关于入口；赞助区按参考设置页内联，不生成独立导航。设置章节用原生Heading与2／3层级，正文用Text保留可访问名称；本地AccessKit兼容补丁只维护标题映射，来源及许可按固定SHA-256清单核验。通知开关已按本次1:1目标启用，启动不申请系统权限。

中性基线命中标准 gpui-gui-common-v1；当前业务页采用上段已批准的参考产品像素覆盖。侧栏 compact，固定 80px、Logo 36px、图标 22px、居中图标/名称上下排列，不折叠。公共设置已迁入应用信息与统一 Agent 五项开关，语言为中英两项（系统探测仅初值），主题保留浅深/跟随系统三态；有实际保存回执及失败保留旧值。更新日志为受控原生弹窗，普通构建保持真实空状态。公共设置包含通知与自启两列卡，以及原样迁入的历史项目微信/支付宝两张本地收款图；用户本次明确授权为达成1:1目标引入所需资源，图片仅展示，不解码重建、不授权支付。GitHub动作是已知历史源码入口，提示中明确LokiMetis，未宣称为新项目仓库。

标题公式为 {applicationName} v{Cargo.version}，名称随 locale，不附加第三方联系方式。负责人已明确要求清除非本人 QQ 联系信息；change_id：`LMDESK-REMOVE-FOREIGN-QQ-001`，required_version：`0.2.57`。应用 identifier=com.loki-metris.app，publisher=ManonLoki；不代表已取得商店/签名资格。系统语言由 sys_locale 读取，未知回退英文；窗口只恢复有效尺寸/位置/最大化，首次/损坏居中 1440×900、最小 960×640。

系统托盘、开机自启、单实例、全局快捷键 enabled；通知与页内赞助 enabled；独立关于页和深链接 disabled。热键 actions=0、初始非空 bindings=0、实际系统注册=0，退出无外部键位需要注销。自启仅有能力，初始化不注册，真实宿主检查后恢复原状态。

三平台登录项统一传入 `--autostart`，手动打开显示主窗，重复登录启动不唤醒已有实例。登录启动隐藏创建主窗，最多异步等待三秒确认托盘恢复入口；成功后保持隐藏，入口缺失或超时回退可见主窗，等待期间的手动显示撤销旧启动意图。Linux X11 的首次映射通过受管 GPUI 补丁遵守 `show=false`，确认隐藏后托盘消失会恢复主窗；纯 Wayland 保留可见回退。Windows Run 值与 Linux XDG 条目均校验当前完整命令，无标记旧项不视为当前有效配置，只在用户重新开启时写入新命令，启动查询不自动改写登录项。该逻辑属于宿主启动机制，不恢复持久隐藏偏好；真实登录启动仍待新版包实测。

macOS 正常启动使用 Accessory 策略并通过包内 `LSUIElement` 隐藏 Dock，旧无参数 LaunchAgent 兼容自身精确服务身份；托盘失败回退普通 Dock 身份。Dock 行为仍待新版包实测。

Linux主窗与辅助窗使用相同`app_id`，最终Debian桌面入口以相同`StartupWMClass`绑定；X11/XWayland活窗从已批准Logo取得64/128像素`_NET_WM_ICON`。托盘恢复入口确认后，主窗申请隐藏Dock/任务栏条目；入口丢失时恢复条目及已隐藏的主窗，纯Wayland保留普通窗口入口，新版Dock行为仍为Unverified。桌宠通过真实宿主控制显隐、几何、置顶、锁定与Shape输入穿透；托盘仅在Watcher及本进程`main_tray`均确认时作为隐藏主窗的恢复入口。协议、失败和纯Wayland边界见Linux工程知识库，源码接入不代表Dock呈现或原生交互已验收。

首次桌宠设置缓存命中不得短路统一Agent启用集合的发布。桌宠偏好保存与Hooks启用门禁分别消费各自权威事实，不能因一次先到的偏好读取让Hooks继续沿用默认空集合；实际事件仍须通过生命周期状态机后才能驱动桌宠和通知。

统一 Agent 选择仅以本应用私有数据目录的 `monitor/monitor-settings.json` 为权威，物理客户端集合由 core 能力目录派生，不另外持久化副本。配置读写上限为128 KiB，拒绝非普通目标文件；成功原子落盘后才发布已确认值。保存由应用级 owner 持有，离页不取消已接受提交；主题、语言与窗口几何按各自字段合并，不能互相覆盖。缺失配置默认启用 Codex、Claude Code、Cursor，明确空集合保持空，停用 WorkBuddy 不探测其文件。

图片独立圆角视口兼容层仅在上游提供等效能力、且本项目相同几何、资源和目标平台像素/交互回归通过后移除。不得为移除补丁而取消失败验证，macOS 结果不替代 Windows 或其它后端证据；实际版本与补丁归属仍取根 Cargo 及 vendor 维护说明。

额度行按“短标题 → 重置倒计时Tag → 右侧剩余百分比”排列，中文标题为`5h`、`本周`、`本月`，英文为`5h`、`Weekly`、`Monthly`。行高20px，标题与Tag间距8px；重置Tag沿用20px高、11px字、水平内距8px、圆角6px及主题muted/border/muted_foreground，超长文字省略且辅助标签保留全文。没有重置时间则省略Tag并保留行高；百分比不收缩，进度条仍高8px。此为用户明确批准的展示调整，额度值及重置计算继续消费既有快照。change_id：`LMDESK-QUOTA-ROW-LABEL-TAG-001`；required_version：`0.7.6`；关联ADR-20261022-002。

AI监控已接通工作台、监控管理、图片管理与Hooks设置。工作台三秒读取本应用环回监听状态、已接收/失败计数与最近事件；额度卡在有任一真实额度窗口时显示，当前顺序为 Codex、Claude、Cursor、Grok；WorkBuddy 已移出读取目录，Claude 取自受管 statusLine 写下的本机记录（ADR-20261021-017）。等待、凭据缺失、读取失败或完全无窗口均不占位，全部不可用时隐藏整个额度面板；缺失的五小时、周或月额度行单独隐藏，只有周额度或只有 Cursor 月额度仍显示进度条。进度条高8px、圆角胶囊，长度表示剩余比例，剩余≤20%使用主题danger红色，20%<剩余≤50%使用warning黄色，>50%使用success绿色；保留百分比、方案与重置时间辅助标签，不只依赖颜色。每卡沿用14px内边距与12px圆角，内部间距12px；栅格保持窗口宽≥768px两列，否则一列。优先使用本机已有记录里能归类的窗口，两种都没有时才只读登录材料并以官方客户端标识访问用量接口；月度账单不算周窗口，只有 Cursor 账单月显示为本月，用量约五分钟刷新且与 Hook 快照分开。change_id：`LMDESK-MONITOR-QUOTA-DISPLAY-001`；required_version：`0.7.0`；关联ADR-20261021-013。周额度误隐藏更正：`LMDESK-QUOTA-WEEKLY-VISIBILITY-001`，required_version：`0.7.1`。可见失焦窗口继续刷新，隐藏后暂停页面读取，监听与状态机独立运行。管理页使用统一启用集合，保留各 Agent 的位置、四行为图片及多行草稿，原子合并保存不覆盖其它 Agent；图库支持原生文件选择、批量导入、格式筛选与受引用约束的删除。静态图、GIF 与 APNG 使用实际像素，动画支持有限次数、失焦继续及隐藏恢复；纹理边缘保护避免小图放大混入图集邻块。图片只在实际可见位置解码，按App登记图库entry、播放器与桌宠整页需求；一个位置离屏、离页或窗口隐藏不驱逐其它窗口的同ID资源，最后owner离开才释放缓存与所有存活窗口的全部GPU帧。窗口关闭与Entity释放独立收尾，迟到旧entry不影响新entry；保留各位置时间线，显式刷新只重试已失败资源并通知实际owner，健康及pending资源继续共享。解码最多并发2项，CPU保留像素总预算512MiB，不等同进程峰值。Hooks设置按统一Agent集合提供目录草稿、保存、恢复默认及真实写入回执；可复制文件路径只读，未保存草稿禁止写入，异步回执不覆盖后续输入。原子写入只维护本应用marker，保留参考应用及用户配置；Windows WSL宿主路径尚缺真实Windows证据。桌宠已接通独立透明原生窗、六布局／十二位置分页、Hook图文投影、动画和独立深色设置；布局、尺寸、置顶、锁定与位置在应用级串行保存，正常退出排空待提交意图。设置可关闭重开和返回主界面；主窗隐藏不隐藏桌宠，托盘可切换浮窗显示。macOS辅助尺寸赋值与退出重启已实测；无边框窗保留FullSizeContentView，按历史宿主激活并可由原生Window菜单访问。桌宠主体双击／右键已用真实指针观察，方向键消费与悬停保留已补回归，第七次预览已实测方向键、滚轮及原生分页按钮的边界回绕；第八次预览普通解锁拖动仍未改变位置，原生鼠标事件分支正在定位；Windows宿主尚未实测。图库与选择器圆角使用独立原视口绘制接口，图片和棋盘共享圆心，Metal像素与资源回归通过，第11次预览已观察触发区、选项和图库上沿裁切；文字阴影、材质和其它控件仍待收敛。macOS 字体附加笔画膨胀仅在进程内关闭，系统持久偏好不变。

## 应用换肤当前实现

GPUI皮肤页使用统一启用Agent集合筛选Codex／WorkBuddy宿主，提供响应式卡片、搜索、用户资源多选、创建纯主题与生成提示词、原生ZIP选择／预检／信任／导入、导出及转换／删除确认。资源事务属于应用级后台owner；页面离开后预检暂存取消，已接受提交仍完成并清理。宿主操作保留实例身份、代码／外观／Windows整宿主恢复授权，排队操作失去页面授权后不能启动新副作用；已进入事务的补偿不被GUI授权检查阻断。

六套内置皮肤和生成器随包进入macOS `Contents/Resources/skins` 或Windows/Linux安装根 `resources/skins`；release只读取包内资源，缺失明确报错。注入runtime、兼容层与事务标记使用LokiMetris独立命名空间，发现原版owner后拒绝接管；自有旧回调停止并保留共享状态清理账本。创建／预检／纯主题提交／导出已有macOS开发预览观察；WorkBuddy已完成当次授权的应用／停用及正常实例恢复，Codex与Windows宿主、最终视觉仍未验收；本地App包内资源实际运行已观察。预览保留参考Card.Section负边距：内部176px高、左右扩16px并上移16px，外层实际可见160px；居中Cover不改原图。安装参考版v0.3.12的实际Brotli嵌入代码／CSS与历史dist完整匹配，六套预览资源三方字节相同。图片圆角沿外卡片1px边框内缘使用19px，选择框同步分区位置；真实窗口几何／图元4项与消费者3项通过。选择框圆角外的绘制／命中仍有真实差异，实物构图待新版对照。

### 通知纵切

当前规则与边界以[最新产品规格](product_spec/20261020_product_spec.md#托盘自启与系统通知)为准。`LMDESK-TRAY-NOTIFICATIONS-001`（required_version `0.3.0`）将旧每100M规则替换为当天首次严格超过1B，并增加Hooks询问/结束/错误及换肤成功/失败通知；托盘同时增加真实OS状态的开机自启入口。设置、托盘与原生菜单共享已确认通知偏好与权限。独立今日摘要仍供桌宠显示；用量读取失败只暂停Token通知。瞬时事件与Token共用原生owner和生命周期。开发回归不替代OS横幅、点击、登录启动或跨平台正式验收。

macOS Kit初始化已先注册GPUI通知代理；应用仅对该已知类建立协作桥接，强持有原代理并转发非里程碑通知及可选系统设置回调，不替换Kit的App回调。未知代理保持失败关闭；退出只在槽位仍属自身时恢复原代理。通知worker关闭会取消正在等待的只读摘要，拒收新回执并排空已接受结果的文件事务，不等待OS完成块或继续预约。正常退出与横幅、点击仍须以新候选实机复核。

macOS 显式授权后会复读真实系统权限；`UNErrorDomain=1` 而状态仍为 NotDetermined 时报告不可用，不伪装用户拒绝或跳转不存在的应用通知设置。local App/DMG 与开发预览都绑定完整 ad-hoc bundle 身份；仅凭签名与回归通过仍不能宣称系统通知列表、授权或横幅已经恢复。
