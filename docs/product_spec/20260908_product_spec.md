# Product Spec：LokiMetis 本机 AI 工作台与多宿主换皮

> 状态：Approved
> 记忆日期：2026-09-08
> 用户确认依据：延续 2026-09-07 已批准的用量看板、Hooks 监控、桌宠、Codex/WorkBuddy 换皮与统一 Agent 选择范围。用户本次先明确要求将公共设置中的“扫描间隔”与“自动清理”提取到“用量看板”中，并在“数据源”后新增“设置”选项卡承载；随后根据换皮页截图明确要求删除工具栏中的宿主进程选择框与皮肤结果计数，并进一步要求 Codex、WorkBuddy 都不显示显式启动按钮，同时隐藏“只看用户皮肤”；又明确把侧栏中文一级入口从“应用换皮”改为“应用换肤”；最后要求在系统托盘图标右侧显示当天全部已启用来源的 Token 总数，当天没有用量记录时不显示文字，并指定用十进制 `K`/`M`/`B`、两位小数和千分位展示。

## 产品目标

LokiMetis 是面向 Windows、macOS 与 Linux 的 GUI-only 本机 AI 工作台：聚合本机 AI Agent 用量，管理本机 Hooks 监控与桌宠展示，并为受支持的 Codex、WorkBuddy 桌面宿主提供本机外观管理。所有公开 Agent 由一个全局复选面板启用，各业务页面只投影自身支持的子集；扫描节奏与派生数据保留归属用量看板。所有皮肤资源与偏好保留在本机，应用或停用外观只连接经过对应宿主标记验证的本机渲染页面。

既有稳定变更为 `FEAT-CODEX-SKIN-MANAGEMENT`、`FEAT-SKIN-CATALOG-MANONLOKI-AUTHORSHIP`、`FEAT-WORKBUDDY-SKIN-HOST`、`FEAT-UNIFIED-AGENT-SELECTION-PANEL` 与 `FEAT-MONITOR-HOOKS-NAVIGATION-LABELS`，其已记录 `required_version` 继续有效。

本次用量设置归属变更的稳定 `change_id` 为 `FEAT-DASHBOARD-SOURCE-SETTINGS-TAB`，版本门禁给出的 `required_version` 为 `0.2.14`。

本次换皮工具栏精简的稳定 `change_id` 为 `FEAT-SKIN-TOOLBAR-SIMPLIFICATION`，版本门禁给出的 `required_version` 为 `0.2.14`。

本次跨平台安装显示名本地化的稳定 `change_id` 为 `FEAT-LOCALIZED-PACKAGE-DISPLAY-NAME`，版本门禁给出的 `required_version` 为 `0.2.16`。

本次移除换皮页显式启动入口与用户皮肤专属筛选的稳定 `change_id` 为 `FEAT-SKIN-LAUNCH-AND-USER-ONLY-REMOVAL`，版本门禁给出的 `required_version` 为 `0.2.16`。

本次换肤入口中文名称调整的稳定 `change_id` 为 `FEAT-SKIN-NAVIGATION-LABEL-RENAME`，版本门禁给出的 `required_version` 为 `0.2.16`。

本次托盘当天 Token 总数的稳定 `change_id` 为 `FEAT-TRAY-DAILY-TOKEN-TOTAL`，版本门禁给出的 `required_version` 为 `0.2.16`。

## 当前包含

- 固定 compact 侧边栏的三个一级业务入口依次命名为“用量看板”/“Usage Dashboard”、“AI监控”/“AI Monitor”、“应用换肤”/“App Skins”；不改变 80px 侧边栏几何、图标、顺序或底部公共设置入口。
- 公共设置页展示应用、版本、本地更新日志、语言、主题、通知、自启与唯一 Agent 复选面板；不再展示扫描间隔或自动清理。
- 用量看板在物理 Agent 与 WorkBuddy 视图的“数据源”后显示“设置”选项卡；该页只承载全局扫描间隔与自动清理，“全部”视图不显示用量设置。
- Hooks 目录、配置文件与写入操作位于“AI监控”下的“Hooks 设置”二级选项卡，只消费统一 Agent 选择，不复制启用复选面板。
- 打包并只读展示六套内置皮肤，排除“极光静界”，且内置清单作者统一为 `ManonLoki`；扫描 LokiMetis 应用数据目录中的用户皮肤，不改写用户皮肤作者信息。
- 换皮页按统一启用集合与能力映射动态展示 Codex、WorkBuddy 选项卡，各选项卡独立保存当前进程中的查询状态、活动皮肤和恢复提示。工具栏只保留搜索、导入、创建主题与刷新，不显示宿主进程选择框、筛选结果计数、“只看用户皮肤”或任何 Codex/WorkBuddy 显式启动按钮；发现唯一实例时自动作为操作目标，发现多个实例时不静默选择并阻止需要目标的操作。
- 支持皮肤搜索、预览、本机 ZIP 导入导出、纯主题创建、兼容皮肤转换、打开用户目录与经确认删除；路径穿越、链接、超限、非法清单与资源引用必须被拒绝且不留部分结果。
- 支持发现 macOS 与 Windows 上已验证的 Codex 或 WorkBuddy GUI 实例；只通过回环地址 CDP 连接并按宿主验证页面。需要重启时只操作用户明确选中的 GUI 主进程，且须先展示风险并二次确认。
- 记住最近一次成功应用的皮肤；只在同一目标已就绪且当前无活动皮肤时提供用户可点击的一次性恢复，不自动注入或建立新后台常驻任务。
- 所有用户可见文案提供简体中文与 English；浏览器预览安全降级，不声称拥有原生文件、进程或 CDP 能力。
- Windows 安装器明确提供 English/简体中文选择，安装器标题、快捷方式与“已安装的应用”名称分别显示 `LokiMetis`/`诡秘神谕`；macOS Finder 应用名按系统首选语言显示对应名称。安装包、DMG、`.app`、安装目录和注册表键等物理或稳定身份保持 `LokiMetis`，不因运行时语言产生重复产品身份。
- 系统托盘使用现有“全部”视图的设备当地自然日口径，读取全部已启用本机 Agent 与已启用 WorkBuddy 的联合 Token 总量；当天至少存在一条用量记录时在图标右侧按十进制千进位显示 `K`/`M`/`B`，固定保留两位小数，超大整数部分使用逗号千分位；不足 `1,000` 时显示原整数。没有当天记录或联合读取失败时清空标题。macOS 原生显示该标题，Linux 由桌面托盘实现决定是否可见，Windows 因原生托盘不支持标题而只保留图标。

## 当前不包含

- 不新增 CLI、TUI、MCP adapter、应用 updater、全局快捷键、赞助页、关于页、外部网站、更新检查、产品统计、远程日志、远程遥测或新网络服务。
- 不自动应用、自动恢复或后台轮询注入皮肤；皮肤应用、停用、恢复、导入、导出、删除与进程重启都由真实用户动作触发。
- 不修改 Codex 或 WorkBuddy 应用包、会话文件、Cookie、钥匙串或认证秘密，不连接非回环调试端点，不承诺 Linux 宿主注入。
- 不把扫描间隔或自动清理复制回公共设置、数据源页或“全部”视图；不改变两项配置的持久化、值域、后台执行时机或错误语义。
- 不在换皮工具栏或资源列表重复显示宿主进程选择框、皮肤结果计数、“只看用户皮肤”或 Codex/WorkBuddy 显式启动入口；不以列表顺序、进程号或调试端口静默选择多个实例中的任意一个。
- 不为托盘计数新增远端数据源、遥测、单独数据库、前端常驻查询或第二条轮询任务；Windows 不以悬浮窗、通知或修改图标绘制来模拟原生不支持的标题。

## 假设与约束

- 扫描间隔与自动清理仍是全局设备偏好，选项卡随当前 Agent 视图展示不会把它们变成每 Agent 独立设置。
- 皮肤清单、值域、ZIP 安全边界、稳定错误，以及用量设置的语义校验与持久化策略属于 `loki_metis_core`；文件系统、进程、CDP、对话框、原生拖放与页面路由属于 GUI adapter。
- 用户皮肤只写入 LokiMetis 自身应用数据目录；路径、进程参数与 CDP 响应不得原样进入日志或普通错误文案。
- CDP 连接、账户探针、皮肤安装、周期扫描与清理任务必须有 owner、取消路径、有界超时与关闭回收，不得遗留 detached task。
- 换皮操作只在发现恰好一个宿主实例时自动确定目标；多个实例并存时以可操作错误提示用户先关闭多余实例，再刷新重试。
- 托盘标题只投影现有联合用量聚合：扫描、清空索引、来源启停、Agent 选择变化和既有共享扫描节拍触发刷新；读取失败必须隐藏而不是沿用可能过期或少算的旧标题。

## 可观察成功标准

- 物理 Agent 或 WorkBuddy 视图的看板横向导航中，“设置”紧跟“数据源”；点击后路由为 `/dashboard/settings`，可见且只可见扫描间隔与自动清理这两类用量配置。
- “全部”视图不出现“数据源”或“设置”；切换到“全部”时不保留不适用的用量设置路由。
- 公共设置仍包含唯一 Agent 复选面板、应用信息、语言、主题、通知、自启与本地更新日志，但不再出现扫描间隔或自动清理。
- 扫描间隔与自动清理保持原有合法值域、保存成功/失败反馈、查询同步和实际后台语义，中英文界面均有可访问名称与键盘路径。
- Agent 面板中每个公开 Agent 只出现一次；保存后看板、Hooks、桌宠与换皮在同一权威快照上收敛，不支持的区域不伪装能力。
- 中文侧栏的 `/skins` 一级入口显示“应用换肤”，英文继续显示 “App Skins”；图标、路由、顺序、活动状态、键盘路径和 80px compact 几何保持不变。
- 六套内置皮肤不出现“极光静界”且作者均为 `ManonLoki`；合法用户主题可发现并保留自身作者，非法目录、ZIP 或目标页面被安全拒绝。
- Codex 与 WorkBuddy 换皮工具栏都只保留搜索、导入、创建主题与刷新，不出现宿主进程选择框、“只看用户皮肤”或任何显式启动按钮；资源区不显示“显示 N 个皮肤”或对应英文计数。唯一实例仍可正常操作，多个实例不会被静默选中并得到关闭多余实例的明确提示。
- Windows 选择 English 或简体中文完成安装后，安装器和系统入口分别显示 `LokiMetis` 或 `诡秘神谕`，重启安装器/卸载器继续使用已保存语言；macOS 在 English 与简体中文系统首选语言下分别显示 `LokiMetis` 与 `诡秘神谕`，其他语言回退 English。
- macOS 当天存在联合用量记录时，菜单栏应用图标右侧显示当天 `total_tokens`：`1,000 → 1.00K`、`1,234,567 → 1.23M`、`75,528,253 → 75.53M`，四舍五入跨单位时继续晋级；当天无记录、联合读取失败或日期切换到尚无记录的新一天时不显示标题。Windows 始终只显示托盘图标；Linux 不承诺所有桌面环境都渲染标题。
- 相关 React 回归测试非空并通过；本次不改变 core 领域行为或 Rust 宿主机制，不把开发测试声称为发布候选验收。
