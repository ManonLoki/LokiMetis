## 目标与范围

为本机 AI Agent 使用者提供与参考产品一致的用量聚合、Hooks 监控、桌宠与 Codex/WorkBuddy 换肤工作台。保留当前已确认的 LokiMetris 双语名称、独立应用身份与所选金色神谕之眼 Logo；业务布局、可见交互、默认值、错误与持久化语义以参考产品为基准。

包含：

- 80px compact 导航：用量看板、AI监控、应用换肤，底部公共设置。
- 公开 Agent 唯一选择：Codex、Claude Code、Cursor、Grok、WorkBuddy；各业务只显示实际支持的子集。
- 看板概览、调用、统计、图表、数据源、扫描设置、快速/完整扫描、取消、索引与安全清理；固定自然日窗口和历史 Token 口径保持一致。
- Hooks 配置、监控工作台/档案/图片、桌宠多窗口、状态联动与布局偏好。
- 内置与用户皮肤的浏览、搜索、预览、创建、ZIP 导入导出、删除、宿主发现、可信回环 CDP 应用与停用。
- 中英文、浅深/系统主题、设置持久化、托盘计数、通知、自启、单实例及参考产品已有的安全宿主交互。
- 每阶段实际运行 GPUI，使用 Computer Use 对照参考 App。最终完成要求真实功能、交互与视觉证据同时收敛。

不包含：新增产品功能、远端遥测、应用 updater、发布/推送/签名/渠道分发、覆盖已安装参考 App、迁移或删除用户原始会话、自动注册 Hooks、自动注入皮肤或未经确认重启其它宿主。

## 事实与约束

- 参考源码根 Cargo 为 `0.3.15`，安装 App 实测显示 `v0.3.12`。源码可能含未提交修改，保持只读；对具体差异以实际 UI 与源码证据分别记录，不假定二者相同。
- 复用无 Tauri/WebView 依赖的领域 core。GPUI 使用原生 Rust 视图；不得以嵌入网页实现替代。
- 新 App 的索引、设置、图片和皮肤数据使用独立目录；只读扫描原始 Agent 数据。两个 App 不共用 writer、relay 或运行时所有权。
- 窗口线程不执行阻塞 I/O。后台任务具有 owner、取消、边界与退出回收；稳定错误不泄露任意路径、内容或凭据。
- 皮肤导入的脚本信任与宿主重启保持原有确认语义。UI 比对不自动授权真实系统配置、支付、消息发送或破坏性操作。
- GPUI 原生能力缺口需要真实实现与验证；不得把 unavailable、占位、Mock 或源码存在描述为体验一致。

## 成功标准

1. 对参考产品全部页面、状态、控制与默认值建立可追溯差异清单，所有范围内差异关闭。
2. 原始用量在同一数据来源、时间和筛选下得到相同聚合；缺失/零、缓存、推理、重复、边界时间与错误保持一致。
3. 页面切换保留当前进程内会话，真正退出按参考语义重置；设备偏好正确恢复。
4. Hooks、桌宠、皮肤使用同一权威 Agent 集合，安全边界与实际系统效果保持一致。
5. 必要非空回归通过；每阶段完成 Computer Use 实测。当前 macOS 证据不冒充 Windows 证据；未验证项不算通过。
