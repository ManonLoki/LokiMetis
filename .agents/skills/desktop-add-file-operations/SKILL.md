# 接入文件操作

读取 [文件操作合同](references/file-operations.md)，并只读取当前项目已批准的输入、输出和数据变更边界。文件系统驱动与 core 的归属遵守项目工程规则。

## 执行

独立调用时先进入 `$desktop-implement-change`，在任何代码写入前完成其仓库、分支和适用版本门禁；已经由该流程调用时复用同一实施上下文，完成后返回当前步骤，不重复生命周期。

1. 确认实际需要读取或写入的对象、允许范围、冲突/覆盖、权限、部分写入和恢复语义；缺失且会改变产品边界时返回 `$desktop-define-product`，不自行选覆盖策略。
2. 复用标准库与项目已有依赖，在 core 实现领域策略和稳定错误，在基础设施或对应 adapter 实现具体 I/O；只在真实消费者需要时增加抽象。
3. 按项目已经选择的接口接线：CLI 才处理标志、JSON、标准流和退出码；TUI/MCP/GUI 使用各自协议或交互映射。不得因文件操作额外增加 CLI。
4. 实现已批准的安全写入与恢复行为，运行受影响的 core 成功/最高风险失败回归和实际修改接口的映射测试。变更型测试使用隔离临时目录并证明原数据保留。
5. 按 `$desktop-implement-change` 完成本次变更；本 Skill 不自动增加构建、候选验收、远端操作或项目记忆。

## 完成

报告读写范围、覆盖和失败策略、core/driver/adapter 映射、实际测试与未验证平台。功能移除时同步删除能力专用实现、特性与依赖，不保留无消费者框架。
