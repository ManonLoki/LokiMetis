# GUI 支持界面差异

> 仅当终端下游明确修改 Harness 固定支持界面或增加新支持页时，复制本模板为 `docs/GUI_SUPPORT_SURFACES.md`。初始化不创建本文件的实例。

## 基线差异

- change_id：待填写
- required_version：待填写
- GUI profile（含 `sidebar_mode`）：待填写
- 受影响路由/组件：待填写
- 与 `docs/GUI_APP_PROFILE.md` 的关系：待填写
- 可见行为与无障碍名称：待填写
- i18n 键与英文回退：待填写
- core/GUI 所有权理由：待填写

## 本地媒体

- 更新日志：核对根 `release-notes.json` 与候选内资源一致。
- 赞助媒体：核对清单声明的 12 个源文件。
- 来源与许可：待填写
- bundle 路径：待填写
- MIME、尺寸、字节数与 SHA-256：待填写
- 敏感材料与处理限制：待填写
- 禁用时零残留证明：待填写

## 外部链接或宿主能力

- 目的与用户触发器：待填写
- 允许的 origin/路径：待填写
- 权限与失败语义：待填写
- 秘密来源引用（不写实值）：待填写
- 超时、取消、回收与日志脱敏：待填写

## 验证清单

- [ ] 页面、入口、文案与 profile 一致；禁用项没有隐藏路由或资源。
- [ ] 设置页固定包含应用/版本、语言、主题和本地 release notes，并只增加 profile 已启用的宿主开关。
- [ ] 设置页从候选本地资源读取近五版双语 release notes，失败可重试。
- [ ] 事件绑定实际控件，父容器不代理子控件动作。
- [ ] 品牌媒体清单与 bundle 字节一致，支付码未被处理。
- [ ] 新外部能力具备明确授权、最小权限、超时、取消和失败语义。
